# Cocinas Pro

PWA de interiorismo de cocinas: medición en milímetros, plano 2D editable, mobiliario paramétrico con comprobaciones, alzados, 3D (three.js), acabados, igualación con fotografía y expediente técnico.

Abrir: https://rmartinrosado.github.io/cocinas-pro/

Los proyectos se guardan en el navegador del dispositivo (localStorage). Usa «Más → Importar / exportar» para copiarlos entre dispositivos.
